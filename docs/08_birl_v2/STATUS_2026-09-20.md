# BIRL 模型重估：实验现状（2026-09-20）

给合作者的说明。所有数字来自 2026-09-19 至 20 在 Rorqual（Calcul Québec，H100）上的运行，代码与输出在 `Formal Analysis/08_BIRL_v2/`。

## 一句话

原模型"从作物选择估出 CRRA 风险厌恶 ρ 和 Stone-Geary 生存线 γ"这件事做不到，也不是重跑能救的；换成数据支持的半参数选择模型后，得到了识别良好、跨国可比的两个量：**离散度回避**（六国一致）和**收入水平敏感度**（随发展程度递增）。paper 需要重新定位，但数据管道、环境模型、动作空间、气候情景全部保留。

## 1. 为什么重做

对 v1.1 结果的诊断发现三个问题，都是参数化造成的伪影，不是数据问题：

| 问题 | 证据 |
|---|---|
| γ 的上界 30 美元来自六国混合的每块地收成中位数，被 Mali/Nigeria 拉高；Ethiopia/Malawi/Uganda 的中位收入只有 19 到 25 美元 | Ethiopia、Malawi、Mali 的 γ 后验贴 30；这三国 γ/收入中位 = 1.3 到 1.5；87% 到 93% 的效用格子至少一个积分点被硬截断 |
| reward 只去均值不除标准差，效用尺度随 ρ 变化，一个全局 β 无法同时服务高低 ρ 的家庭，ρ 实际充当"家庭温度"，与选择噪声混淆 | β = 0.14；家庭级 ρ 中位数落在平坦区，σ_ρ^W = 2.07 是 sigmoid 饱和 |
| 3.1 万个家庭级参数不可识别（每户中位 11 个观测、4 种作物） | TPU 上 6.9 秒一个 draw，树深顶满 |

政策结论也随之不稳：把 γ 换成收入中位数的 0.3 倍重算，"安全网 vs 保险差 40 到 65 倍"缩到约 6 倍，Ethiopia 的排序在 γ 份额 0.1 下反转。CE/Income > 1 是分母错配（分子取最优动作，分母取实际收成）。

## 2. v2：重参数化后的结果

模型改为国家级参数（去掉家庭层）、γ = s·m_c（s 为收入份额，上界 0.6）、reward = 确定性等价 / 收入中位数、平滑下限。NUTS 4 链 × 1000，整卡 H100 17 分钟。

| 国家 | ρ 中位 [89% HPDI] | s | β |
|---|---|---|---|
| Ethiopia | 4.99 [4.94, 5.00] | 0.594（贴上界） | 0.07 |
| Malawi | 0.106 [0.10, 0.13] | 0.52 [0.16, 0.60] | 0.04 |
| Mali | 4.99 [4.96, 5.00] | 0.125 | 0.43 |
| Nigeria | 4.92 [4.66, 5.00] | 0.157 | 0.89 |
| Tanzania | 0.106 [0.10, 0.17] | 0.579（贴上界） | 0.05 |
| Uganda | 4.82 [0.10, 4.99]（双峰） | 0.594（贴上界） | 0.07 |

散度 10.7%。s 上界放到 0.8 时三国的 s 跟到 0.8；s 固定 0.3 时 ρ 仍贴边。PPC 预测的作物频率对所有作物在 4% 到 6% 之间（近似均匀），实际是 Malawi 玉米 21%、Uganda 树作物 17%。相对"可行作物内均匀选择"，对数似然增益只有 0.012 nat/观测。

**结论：在 CRRA/Stone-Geary 族内，ρ 和 γ（或 s）不可识别。** 这不是采样器的问题：模拟回收测试 36 项过 33 项（失败的三项都是已知的 s-ρ 替代区）。

## 3. 排除了两个"数据有问题"的解释

**环境模型泄漏。** Step 04 对 85% 的家庭是样本内预测。把选择模型分别在训练行和 15% 留出家庭上拟合：结构部分增益 0.084 vs 0.081 nat/观测，σ 系数和 q10 权重几乎一样（Nigeria q10 权重 2.54 vs 2.46）。**无泄漏。**

**σ 是陌生度代理。** 可行集内 σ 与本地种植频率的相关全样本 +0.01、各国符号不一；加国家×zone×作物固定效应后 σ 效应保留 85% 以上；按所选作物本地常见/罕见分组，系数相同。**σ 是真实的产出可靠性信号。**

## 4. 数据里到底有什么：存在性检验与效用族扫描

三分位数权重检验（控国家×作物固定效应）：q10 的权重是 q90 的 2 到 14 倍（Nigeria 3.02 vs 0.22，t = 237；Mali 1.75 vs 0.31；Ethiopia 0.70 vs 0.08；Uganda 0.67 vs 0.33；Tanzania 0.21 vs 0.11；Malawi 无差异），似然比 23,598（12 df）。选择跟踪的是预测收入的第 10 百分位。这解释了 ρ 为何贴边：CRRA 在 ρ 很大时 CE 趋近最低节点，是这个函数族在模仿"只看 q10"的行为。

效用族扫描（全部带国家×作物固定效应，SVI 点估计，N = 222,023）：

| 效用族 | 对数似然 | 相对风险中性 |
|---|---|---|
| 仅固定效应（β = 0） | −581,742 | |
| 风险中性 log E[y] = μ + σ²/2 | −572,302 | 0 |
| CRRA 闭式（ρ 自由） | −571,412 | +0.004 |
| 秩依赖 Prelec / 期望短缺 | −566,484 / −566,781 | 约 +0.01 |
| Roy 安全第一 / 破产概率 / Kataoka | −575,978 / −573,989 / −574,520 | 为负 |
| **自由 aμ + bσ + cσ²** | **−563,708** | **+0.039** |

没有一个经典族接近自由形式。自由系数的形状六国一致：a ≈ 0.2 到 0.4，b ≈ −2 到 −3，c ≈ +1，在 σ ≈ 1.2 处触底的 U 形。

## 5. 半参数模型的正式估计

V = a·μ + b·σ + c·σ²，μ = log 中位收入，σ = log 收入离散度，加国家×作物固定效应，国家级 (a, b, c)，无边界、无 sigmoid。NUTS 4 链 × 1000，0 散度，r̂ ≤ 1.003，ESS ≥ 2300，整卡 H100 6 分钟。

| 国家 | a（水平） | b（σ 一次项） | σ*（U 形最低点） |
|---|---|---|---|
| Nigeria | 1.71 [1.67, 1.75] | −9.00 [−9.29, −8.74] | 1.17 [1.15, 1.18] |
| Mali | 1.34 [1.28, 1.41] | −9.11 [−9.54, −8.70] | 1.12 [1.10, 1.15] |
| Uganda | 0.91 [0.86, 0.96] | −11.13 [−11.43, −10.84] | 1.07 [1.07, 1.08] |
| Ethiopia | 0.41 [0.39, 0.43] | −5.42 [−5.54, −5.30] | 1.10 [1.09, 1.11] |
| Tanzania | −0.09 [−0.18, 0.00] | −10.81 [−11.33, −10.32] | 1.23 [1.21, 1.25] |
| Malawi | −0.63 [−0.71, −0.55] | −6.30 [−6.73, −5.88] | 1.31 [1.29, 1.34] |

读法：离散度回避在六国全部显著、强度相近；对收入水平的敏感度 a 才是异质的，排序与国家收入水平几乎单调（Nigeria、Mali 强，Ethiopia 弱，Tanzania、Malawi 为零或反向）。结构部分相对固定效应空模型的增益 0.081 nat/观测。

## 6. 这意味着什么

**成立的：** 农户作物选择对预测收入离散度有强烈、非线性、跨国一致的回避；对收入水平的看重随发展程度递增；这些量识别良好、跨设定稳定。

**作废的：** v1.1 的 ρ、γ 数值，安全网 vs 保险的反转及其倍数，以及"α 不可识别"作为卖点。

**γ 去哪了：** γ 想表达的"对坏结果的敏感"被证实且比原想的更强，但载体从一个美元门槛变成 σ 的系数。数据支持"存在生存压力驱动的下行回避"，不支持"存在一条可估计的生存线"（三个版本的门槛参数全部贴边）。

**定位：** 从"结构性偏好估计"降到"结构性作物选择模型 + 显示的离散度回避"。a、b、c 是稳健经验规律的系数，不是效用函数参数；福利计算中的 ρ 改为校准加敏感性。

## 7. 保留意见（审稿人会打的地方）

1. σ 是模型预测的离散度，农户看不到它；把 b 称为"厌恶"需要论证 σ 捕捉了农户感知的可靠性。
2. 只有横截面结构：家庭固定效应下对冲击的动态反应为零。未做家庭×作物固定效应（"我以前种过"）。
3. U 形右支（σ > 1.2 后偏好上升）未解释，可能是现金作物的彩票效应。
4. 成本变量单位有问题（Nigeria 投入成本算出为收成的 17 倍，Uganda 为 0），成本调整的实验方向可信、大小不可信。
5. Mali 的 σ 与 μ 强负相关（−0.45），该国 σ 效应可能混入水平效应。
